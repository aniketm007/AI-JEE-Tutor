Create a free Supabase project
Takes 2 minutes — completely free, no credit card needed
1
Go to supabase.com and click Start your project
2
Sign in with GitHub (easiest) or create an account
3
Click New project → name it jee-tutor → choose any region → set a database password → click Create new project
4
Wait ~1 minute for it to start up, then come back here
2
Copy your project keys
These connect JEE Tutor to your Supabase database
1
In Supabase, click the Settings icon (bottom of left sidebar)
2
Click API in the settings menu
3
You will see Project URL and Project API keys — copy both values below
3
Create the database tables
One SQL script creates everything needed — runs in 5 seconds
1
In Supabase, click SQL Editor in the left sidebar
2
Click New query
3
Copy the SQL below and paste it into the editor, then click Run

4
Deploy to Vercel (free)
Get a public URL like jee-tutor.vercel.app — takes 2 minutes
1
Go to vercel.com → Sign up free (use GitHub)
2
Click Add New → Project → then Upload (not Git import)
3
Drag and drop your entire jee-platform folder into the upload area
4
Before clicking Deploy, go to Environment Variables and add:
Name: ANTHROPIC_API_KEY
Value: sk-ant-your-key-here
5
Click Deploy — Vercel gives you a URL like jee-tutor-xyz.vercel.app
6
Open that URL → go to /setup → paste your Supabase keys again (browser on the deployed site needs them too)
